# Industrial & Reliability Analytics Portfolio

Hi, I'm Angie — I build data and analytics workflows for **manufacturing operations, production quality, OEE automation, and equipment reliability**, moving away from manual spreadsheet/VBA bottlenecks toward reproducible, code-first Python and BI solutions.

### Core Focus Areas
* **Production Quality & Operational BI:** Turning quality and process metrics into clear visual diagnostics.
* **Automated OEE & Downtime Reporting:** Multi-stage Python ETL, data validation rules, audit logging, and automated Excel/visual reporting.
* **Maintenance & Warranty Log Intelligence:** Explainable NLP text classification (`TF-IDF` + `Logistic Regression`), confidence scores, and high-priority ticket triage.

### Featured Projects
1. **Python Quality Analytics** —  Explores inspection volumes, defect rates, supplier patterns, defect categories and production downtime.
2. **Quality Intelligence Dashboard (Power BI)** — Visual quality monitoring and defect/process insights for manufacturing stakeholders.
3. **Automated Monthly OEE & Downtime Reporting Engine (Python)** — Consolidates daily shift logs, enforces data-validation checks, separates rejected rows into an audit sheet, calculates Availability, Performance, and Quality, and exports formatted Excel workbooks and charts.
4. **Maintenance & Warranty Log Root-Cause Intelligence (Python / NLP)** — Classifies free-text technician notes into failure categories using a stratified train/test split and `TF-IDF` + `Logistic Regression` pipeline, surfaces learned keywords and confidence scores, and flags high-cost/high-downtime tickets for immediate review.
